车辆 API 还需要你的签名材料

密码登录不会生成 API 签名密钥。上游没有个人密钥初始化实现，本项目也不附带作者设备的秘密。没有本人合法持有且配套的材料时，请停在这里；账号登录成功不代表车辆接口已经就绪。

仅含 device_id、key_id、hac_key_hex、app_token。不会自动扫描电脑中的账号或文件。资料如何取得仍需本人解决，不能用随意默认值替代。

签名材料对应的设备与刚才的登录设备不同。继续会舍弃旧登录会话，并使用这套材料的设备重新登录和验证。不会把两个设备身份混用。
